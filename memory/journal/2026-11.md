## J-2026-11-01-M — B-0120 fait : les fichiers de cas protégés, les spécifications jamais soumises signalées

> ref : D-0066, B-0120, J-2026-11-01-L

Un projet déclare ses fichiers de cas dans `[tests] case_paths` des
garde-fous : le contrôle des valeurs attendues refuse qu'un cas existant
change ou disparaisse sans une demande validée qui cite le fichier ;
ajouter un cas, le déplacer ou remettre le fichier en forme reste libre.
Il déclare ses spécifications dans `[specs] paths` : l'état signale à
l'humain celle qu'aucune demande ne lui a soumise. Retirer l'un ou
l'autre des garde-fous assouplit. Un défaut injecté et un témoin sain
l'éprouvent, sur un fichier de cas posé dans le projet d'essai ; les
gabarits des garde-fous, les instructions (point 2), le guide et
l'architecture le disent. Le pilote déclarera les siens à sa prochaine
mise à jour.

## J-2026-11-01-N — B-0122 fait : les questions de cadrage d'un sujet

> ref : D-0067, B-0122

`socle new request --questions` pose une demande de questions de cadrage
d'un sujet, sur le modèle des questions de départ : chaque question
ouverte avec l'hypothèse de l'agent ; `valider` applique les hypothèses,
`reponses` porte le texte libre de l'humain, en un ou plusieurs messages,
que l'agent consigne tel quel avant de soumettre la spécification qui en
découle. Les instructions disent quand s'en servir, et qu'une
spécification se soumet avant son code ; le guide et le format le disent.
Le skill des demandes, protégé dans ce dépôt, n'est pas touché.
