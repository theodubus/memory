# D-0057 — La licence du dépôt public de distribution du socle

> date : 2026-10-31 · forme : séance

## Question posée

La licence du dépôt public de distribution : `mit`, `mpl-2.0` ou `agpl-3.0` ? Ma recommandation : `mit`, conforme à votre règle pour un outil intermédiaire, le socle étant copié dans le dépôt de chaque projet qui l'installe.
