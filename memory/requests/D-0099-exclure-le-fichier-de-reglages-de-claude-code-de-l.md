# D-0099 — Exclure le fichier de réglages de Claude Code de la remise en état d'un fichier protégé par l'agent

> date : 2026-11-11 · forme : séance

## Question posée

B-0165 permet à l'agent de remettre un fichier protégé dans l'état du
dernier commit (D-0098). Le sous-agent y avait inclus le fichier de
réglages de Claude Code, celui qui charge les hooks de l'agent. L'agent a
détaillé le sujet dans la conversation et recommandait de l'exclure : le
gain est étroit, le fichier est le plus sensible du dépôt, et le code de
la remise en état, tout neuf, venait de montrer deux trous en revue. Il a
demandé à Théo de dire « exclure » ou « garder ».
