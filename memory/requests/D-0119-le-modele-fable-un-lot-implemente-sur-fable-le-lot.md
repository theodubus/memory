# D-0119 — Le modèle Fable : un lot implémenté sur Fable (le lot, pas la session qui orchestre), l'agent demande à l'humain, avant la revue, s'il veut aussi Fable pour le relecteur ; et, comme pour la revue, aucun implémenteur sur Fable sauf si l'humain le veut

> date : 2026-11-15 · forme : séance

## Question posée

Une question courte, pour B-0243 : si tu fais implémenter un lot sur Fable, le relecteur doit-il lui aussi passer sur Fable ? Aujourd'hui, le skill dit à la fois « jamais un modèle moindre que celui qui a implémenté » et « Fable seulement si tu le demandes », ce qui ne tient pas ensemble dans ce cas. Ta réponse fixe la règle que le lot B-0236 écrira.
