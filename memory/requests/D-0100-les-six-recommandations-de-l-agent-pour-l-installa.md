# D-0100 — Les six recommandations de l'agent pour l'installation du socle sur chess conviennent-elles ?

> date : 2026-11-11 · forme : séance

## Question posée

L'essai à blanc du 11 novembre sur chess (`docs/fabrication/chess/essai-a-blanc-2026-11-11.md`) laisse six points à trancher à l'installation (B-0126). L'agent recommande :

1. l'adaptateur Rust préparé pour chess (`docs/fabrication/chess/adaptateur.toml`), complété par la session de chess et donné à l'installeur en fichier (B-0168) ;
2. le sous-dossier de l'interface déclaré tiers ;
3. la fusion par l'agent, par une ligne que Théo ajoute à la politique de chess ;
4. une marge au budget du fichier d'instructions, puis un premier sujet de chess pour déplacer le carnet de bord vers la mémoire ;
5. le balayage de mutation de chess gardé, celui du socle non posé pour l'instant ;
6. les branches de réseaux déclarées à garder.

Ces six recommandations conviennent-elles ?
