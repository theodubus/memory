# D-0231 — Les besoins clos de l'étape dépliée de la feuille de route tiennent-ils sur une ligne ou restent-ils un par ligne ?

> date : 2026-11-27 · forme : séance

## Question posée

Dire si les besoins clos de l'étape dépliée tiennent sur une ligne (« ✓ 15 besoins clos ») ou restent un par ligne. Aujourd'hui, comme dans la maquette, chacun a sa ligne : sur ce dépôt, ça fait une quarantaine de lignes de ✓ avant ce qui reste à faire. Si tu dis oui, je le change dans ce lot ; sans réponse, ça reste un par ligne.

Options : `une-ligne` (« ✓ 15 besoins clos ») ou `un-par-ligne` (comme la maquette).
