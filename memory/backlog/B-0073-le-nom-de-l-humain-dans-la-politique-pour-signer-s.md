# B-0073 — Le nom de l'humain, dans la politique, pour signer ses réponses relayées

> statut : ouvert · origine : J-2026-10-20-B · lu : backlog@9b2e2382

Mesuré à la session de bout en bout : sans nom de l'humain dans le
projet, l'agent a signé la réponse relayée (`--by`) du nom git du
conteneur, que `socle answer` et `socle decision` prennent aussi par
défaut. Le nom de l'humain se poserait à l'installation (`[human] name`
dans la politique, à côté du propriétaire déjà demandé), et `--by` le
prendrait par défaut ; un nom différent serait dit.
