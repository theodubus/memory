# B-0113 — La livraison par défaut : une branche de développement et une seule pull request ouverte, une par sujet en option choisie au départ

> statut : ouvert · origine : J-2026-10-31-S · lu : backlog@21d64bbd

Le pilote, en pilote automatique, a ouvert cinq pull requests, longues à
fusionner pour Théo : rien dans les instructions que pose le socle ne dit
comment grouper le travail livré. Théo tranche (D-0058, `branche-de-dev`) :
par défaut, une branche de développement où tout se fait, et une seule
pull request ouverte à la fois, que l'humain fusionne quand il veut ; une
branche et une pull request par sujet en option, choisie au départ.

À faire :
- les instructions (gabarits français et anglais) disent la livraison par
  défaut, l'option, et ce que fait une session neuve qui trouve encore
  ouverte la pull request d'une autre ;
- les questions de départ posent le choix, avec la branche de
  développement pour défaut ; le choix devient un fait de la mémoire ;
- le guide le dit.
