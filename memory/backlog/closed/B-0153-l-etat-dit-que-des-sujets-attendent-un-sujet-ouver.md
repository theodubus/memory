# B-0153 — L'état dit que des sujets attendent un sujet ouvert quand ils attendent une demande

> statut : fait · origine : J-2026-11-10-J · ref : J-2026-11-16-P · lu : backlog@71bf2f52

La dernière ligne de l'ordre du backlog dit « {n} sujet(s) attendent un
sujet ouvert », et la docstring d'`Ordre` de même ; un sujet peut aussi
attendre une demande sans réponse (D-0064), comme sur le pilote
(J-2026-11-10-H). Relevé par la revue de B-0146 (J-2026-11-10-J).

## Satisfait quand

- [x] l'état dit ce qu'attendent ses sujets en attente, sujet ou demande, et un test le montre
