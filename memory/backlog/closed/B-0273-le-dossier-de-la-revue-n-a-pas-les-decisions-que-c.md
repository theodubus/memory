# B-0273 — Le dossier de la revue n'a pas les décisions que citent les décisions écrites par le lot : la spécification validée manque au relecteur

> statut : fait · origine : J-2026-11-16-Y · ref : T-0056, J-2026-11-19-K · lu : backlog@050e512a

Relevé par la revue de T-0047, passe 2 du lot L-0013 (J-2026-11-16-Y),
constat 6, antérieur au lot : le dossier de `socle review` donne les
décisions que citent les entrées du lot (`decisions_citees`), pas celles
que citent les décisions que le lot écrit. Pour T-0047, la spécification
validée par l'humain, D-0124, que cite ADR-0084, manquait au dossier : le
relecteur jugeait sans la barre principale.

## Satisfait quand

- [x] le relecteur d'un lot reçoit la spécification validée que cite une décision écrite par le lot
