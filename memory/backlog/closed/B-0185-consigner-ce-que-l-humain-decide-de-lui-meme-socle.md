# B-0185 — Consigner ce que l'humain décide de lui-même : socle decision exige la réponse à une question que personne n'a posée

> statut : fait · origine : J-2026-11-12-A · ref : J-2026-11-20-AD · priorité : basse · lu : backlog@dac35f16

À l'installation sur chess (`docs/fabrication/chess/installation-2026-11-12.md`, point 7) : `socle decision` exige une
réponse de base. L'agent de chess a consigné sous `valider` six décisions
que Théo avait données de lui-même, avec une « question posée » qui dit
qu'aucune question ne les a précédées ; la session du socle fait de même.
Une forme qui consigne une décision donnée sans question serait plus juste.

## Satisfait quand

- [x] une décision que l'humain donne de lui-même se consigne sans question inventée, son texte exact gardé, et autorise ce qu'elle nomme comme une demande validée
