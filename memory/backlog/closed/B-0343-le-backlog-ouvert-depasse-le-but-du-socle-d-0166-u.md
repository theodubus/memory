# B-0343 — Le backlog ouvert dépasse le but du socle (D-0166) : une part garde contre un agent qui contourne, une autre outille la conduite du travail

Le 24 novembre, Théo redit le but du socle (D-0166) : des outils et une
structure pour que l'agent retienne tout et ait le bon contexte au bon
moment, et des tests automatisés pour le guider ; ni la parade contre un
agent malveillant, ni autre chose. Le backlog ouvert le dépasse : sur
125 besoins et tâches, classés grossièrement par leur titre, environ 41

la conduite du travail, une vingtaine servent la mémoire, le contexte et
les tests (J-2026-11-24-C). Le jalon ne converge pas tant qu'il les
porte.
