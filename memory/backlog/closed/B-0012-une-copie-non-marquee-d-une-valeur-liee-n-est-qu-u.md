# B-0012 — Une copie non marquée d'une valeur liée n'est qu'un avertissement

> statut : abandonné · origine : J-2026-10-10-E · après : B-0104 · ref : D-0168

`docs.valeurs` refuse une valeur marquée fausse, mais ne fait qu'avertir sur
une copie non marquée de la valeur courante : elle pourrait être une
coïncidence. Mesurer les faux positifs avant de durcir.

Abandonné le 24 novembre 2026 par D-0168, le tri du backlog ouvert par le but (`docs/fabrication/tri-du-backlog-2026-11-24.md`), sous « X2 — imaginé par un relecteur, jamais vu, rattrapé ou bénin » : une copie non marquée d'une valeur de la doc n'est qu'un avertissement ; l'avertissement le dit déjà. Il revient s'il est vu en usage réel.
