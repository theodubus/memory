# B-0110 — Une pull request citée sans son lien passe la fin de tour

> statut : fait · origine : J-2026-10-31-O · lu : backlog@2db0833c · ref : J-2026-10-31-O

L'agent du pilote finissait son tour sur « La pull request 2 reste à
fusionner par toi », sans lien : le contrôle de fin de tour ne jugeait que
les chemins, les liens et les demandes. Fait (J-2026-10-31-O) : une pull
request citée par son numéro, sans une adresse qui finit par son numéro,
fait refuser la fin du tour ; un test et un défaut injecté l'éprouvent.
