# B-0186 — Importer un carnet d'avant le socle dont les identifiants ont la forme de ceux du journal

> statut : ouvert · origine : J-2026-11-12-A · priorité : basse · lu : backlog@ff680627

À l'installation sur chess (`docs/fabrication/chess/installation-2026-11-12.md`, point 8) : le carnet d'avant le socle
numérote ses entrées comme le journal (`J-AAAA-MM-JJ-L`). Ses anciennes
entrées ne peuvent pas être citées avant leur migration, le contrôle des
références les disant inexistantes, et la migration se heurtera aux jours
où les deux existent.
