10. Le hook de l'agent a désormais un modèle de menace écrit, que le guide (python3 .socle/socle help) donne : il arrête les erreurs d'un agent coopératif avant qu'elles agissent ; il juge les formes du shell qu'un agent écrit dans son travail, et, quelle qu'en soit la forme, ce que rien ne rattrape ensuite (supprimer le projet ou un dossier qui le contient, une action externe irréversible, une fuite de la mémoire privée). Une écriture d'un fichier protégé sous une forme qu'on n'écrit que pour contourner (un eval, IFS, un chemin construit au vol dans un autre langage) est hors de son modèle : protege.fichiers la refuse ensuite, et un tel trou n'ouvre pas de sujet au backlog. Ce qu'il refuse de plus :
   - la suppression d'un dossier qui contient le projet (rm -rf .., un cd puis ../.., les sources d'un mv, git clean sous -C .., un find qui supprime depuis un tel dossier), et celle du projet par un find qui ne filtre rien (find . -delete) ; un dossier voisin du projet, un dossier du projet et un find qui filtre ce qu'il supprime sous la racine restent libres ;
   - une commande écrite derrière un mot réservé (then, else, do, !, {), comme hors d'une condition ou d'une boucle ; ce qu'une condition ou une boucle change (son dossier, ses variables) devient inconnu après elle. S'il refuse une boucle qui écrit vers une variable qu'il ne connaît pas (while read f; do sed -i … "$f"; done), écris la liste des fichiers en toutes lettres dans un for, ou passe par l'outil d'écriture de fichiers ;
   - la commande qui suit un # au milieu d'un mot ou une substitution aux guillemets imbriqués ("$(cmd "arg")"), qu'il perdait ;
   - ce qu'écrivent cp, ln, install et mv par -t, sort par -o, bash -ec '…' ou bash -c -- '…', find -delete et find -exec rm {} + (par leurs départs et leurs filtres de nom) ; xargs d'un écrivain et python -c se jugent par les chemins protégés qu'ils citent en toutes lettres : lis un fichier protégé par cat ou par l'outil de lecture, pas par un python -c qui le cite, désormais refusé ;
   - le fichier qu'une commande publie (git commit -F, gh … --body-file) se lit depuis ton dossier courant, et non plus depuis la racine.
